<p align="center">
  <strong>SaveLink</strong> is a simple and private browser extension for saving, organizing, and exporting links.<br/>
  All data is stored locally in your browser — no accounts, no cloud, no tracking.<br/>
  It's fast, secure, and built for users who want full control over their saved URLs.
</p>


---

## 🚀 Key Benefits

### ✨ **Ease of Use**
- Save pages instantly with a single click
- Intuitive and modern user interface
- Responsive design for all screen sizes
- Quick access via browser extension

### 🔧 **Advanced Organization**
- Hierarchical link organization into categories and groups
- Drag & drop support for easy rearrangement
- Automatic favicon retrieval for saved pages
- Powerful search and filtering options

### 💾 **Reliable Storage**
- Local data storage directly in the browser
- Automatic backups to prevent data loss
- Fast loading and responsive performance
- Optimized for handling large collections of links

### 🎨 **Customization**
- Light and dark theme support
- Adjustable layout and card sizes
- Configurable keyboard shortcuts
- Personal settings for every user

---

## 🛠️ Core Features

### 📌 **Link Saving**
- **Quick save of the current page** — `Ctrl + S`
- **Save all open tabs at once** — `Ctrl + Shift + S`
- **Context menu support** — right-click on any link to save it
- **Automatic retrieval of page titles and favicons**

### 📁 **Organizing and Categorizing**
- **Create categories** — organize links by topic or theme
- **Category groups** — nested/hierarchical structures
- **Drag & drop** — move links between categories with ease
- **Auto-categorization** — set a default category for faster input

### 🔍 **Advanced Search**
- **Search by title, URL, notes, and categories**
- **Highlight matching keywords** in real-time
- **Filter by category or group**
- **Quick access** — press `Ctrl + F` to open the search

### ⚙️ **Settings & Customization**
- **Theme modes** — light and dark UI themes
- **Layout controls** — number of columns, card size
- **Behavior settings** — open in new tab, delete confirmation prompts
- **Notifications** — customizable toast messages for actions

### 🔄 **Data Management**
- **Edit links** — update titles, URLs, notes, and categories
- **Delete links** — individually or in bulk
- **Duplicate detection** — find and remove repeated entries
- **Import/Export** — safely back up and restore your data

### 🎯 **Productivity Boosters**
- **Keyboard shortcuts** — streamline your workflow
- **Autosave** — never lose your changes
- **Fast performance** — optimized for speed
- **Responsive interface** — works across all modern devices

## 📦 Installation

You can install SaveLink directly from your browser’s extension store:

<p align="center">
  <a href="https://chromewebstore.google.com/detail/EXTENSION_ID">
    <img src="https://img.shields.io/badge/Chrome-Web%20Store-brightgreen?logo=google-chrome&style=for-the-badge" alt="Chrome Web Store" />
  </a>
  <a href="https://microsoftedge.microsoft.com/addons/detail/EXTENSION_ID">
    <img src="https://img.shields.io/badge/Edge-Add--ons-brightgreen?logo=microsoft-edge&style=for-the-badge" alt="Edge Add-ons" />
  </a>
  <a href="https://addons.mozilla.org/en-US/firefox/">
    <img src="https://img.shields.io/badge/Firefox-Coming%20Soon-orange?logo=firefox-browser&style=for-the-badge" alt="Firefox Coming Soon" />
  </a>
</p>

Instruction:
1. Click on your browser's store link above.
2. Click **"Add to [Your Browser]"**.
3. After installation, click the SaveLink icon in your toolbar to start saving links.
4. All your links are stored locally and ready to export anytime.
