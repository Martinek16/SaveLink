## 🚀 Why SaveLink stands out

- <strong>Privacy by design</strong>: everything stays on your computer, no cloud sync, no tracking.
- <strong>Fast and smooth</strong>: loads content as needed, smooth scrolling, and a smart grid layout that works great even with thousands of links.
- <strong>Advanced features</strong>: keyboard shortcuts, right-click menus, choose what to import, finds duplicates automatically, and automatic backups that save space.

---

## 🧠 Advanced capabilities

### 🔍 Search & discovery
- <strong>Search everything</strong>: find links by title, website address, notes, categories, groups, and tags
- <strong>Highlights matches</strong> and shows <strong>smart suggestions</strong> as you type
- <strong>Quick search</strong> with `Ctrl+F` and easy to close or clear

### 🏷 Tags & organization
- <strong>Tags</strong>: add up to 5 tags per link to organize your links your way
- <strong>Manage your tags</strong>: create, edit, and delete tags in Settings
- <strong>Search by tags</strong>: find links using tags along with other search options

### ⭐ Favorite categories
- <strong>Pin categories</strong>: mark your most-used categories as favorites
- <strong>Quick access</strong>: favorite categories appear at the top for instant access
- <strong>Smart limits</strong>: automatically adjusts how many fit based on your screen size

### 🗂 Organization at scale
- <strong>Groups</strong> containing categories to organize your links clearly
- <strong>Drag & drop</strong> categories between groups and re‑order links within categories
- <strong>Smart grid layout</strong> that fits many links neatly on your screen
- <strong>Select multiple items</strong>: choose many links, categories, or groups to work with them all at once

### 📥 Import, Preview & Safe Merge
- <strong>See what you're importing</strong> with checkboxes to choose each item
- <strong>Finds duplicates</strong> for links, categories, and groups, and renames groups if names conflict
- <strong>Choose which settings to import</strong> along with your links

### 💾 Export & Automated Backups
- <strong>Choose what to export</strong> (links, categories, groups, settings)
- <strong>Automatic backups</strong> on a schedule (daily/weekly/monthly)
- <strong>Saves space automatically</strong> and shows file sizes
- <strong>List of backups</strong> where you can restore, delete, see counts, and file sizes

### 🧹 Data quality tools
- <strong>Broken link checker</strong>: checks many links at once and lets you open or delete broken ones from the list
- <strong>Duplicate remover</strong>: finds links organized by website address and removes them with one click
- <strong>Empty category cleaner</strong>: removes empty categories, delete many at once
- <strong>Undo and redo changes</strong>: your history is saved even after closing the extension

### 🔗 Link actions
- <strong>Share links</strong>: share links with a share button or copy to clipboard, includes SaveLink info
- <strong>Middle-click</strong>: open links in new tab without leaving the current page
- <strong>Automatically organize</strong>: suggests categories based on the website address

### ⚡ Performance & reliability
- <strong>Fast and efficient</strong>: loads content as needed and keeps things running smoothly
- <strong>Smooth scrolling</strong> for easy navigation through your links
- <strong>Reliable</strong>: works consistently even with large collections

### 🎯 Keyboard shortcuts & quick capture
- <strong>Keyboard shortcuts</strong>: save page, save all tabs, open SaveLink (`Ctrl+Shift+S/A/L`)
- <strong>Shortcuts inside SaveLink</strong>: search, show or hide sidebar, add link/category, settings, undo/redo
- <strong>Checks for problems</strong>: finds duplicates, warns if shortcuts conflict with your browser, and reset to default settings with one click

### 🎨 Appearance
- Prebuilt themes: <strong>Dark</strong>, <strong>Light</strong>, <strong>Green</strong>, <strong>Blue</strong>, <strong>Pink</strong>
- See how colors look before applying them

### ⚙️ Settings for control
- See how much storage space you're using with live percentage
- Show or hide website icons, notes, headers; choose links per column, card size, and how things fold up
- Set default category and choose whether to ask before doing things
- Option to automatically organize by website address

---

## 📌 How capturing works
- <strong>Right-click menu</strong>: save page or any link with right‑click
- <strong>Extension popup</strong>: edit title/category/notes/tags and save
- <strong>Works on any webpage</strong>: save from any page using keyboard shortcuts
- Automatically gets the page title and website icon
- <strong>Color changes</strong>: extension icon turns green when current page is already saved

---

## 🔐 Security & permissions
- Needs permission to store your links, access the current tab, show right-click menus, and work on all websites for reliable saving and features
- Runs only on your computer, no remote code execution
- Backups saved on your computer with option to download as a file

Quick start:
1) Install from your store above.
2) Press <strong>Ctrl+Shift+S</strong> to save the current page or <strong>Ctrl+Shift+A</strong> to save all tabs.
3) Open SaveLink to organize, search, import/export, and schedule backups.
